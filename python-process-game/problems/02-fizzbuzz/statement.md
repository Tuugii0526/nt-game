# FizzBuzz

Read a single integer `N` (1 ≤ N ≤ 1000) from standard input.

For each integer `i` from `1` to `N` inclusive, print **one line**:

- `Fizz`     if `i` is divisible by 3 but not 5
- `Buzz`     if `i` is divisible by 5 but not 3
- `FizzBuzz` if `i` is divisible by **both** 3 and 5
- otherwise the integer `i` itself

## Input

A single integer `N`.

## Output

`N` lines following the rules above.

## Example

Input:

```
5
```

Output:

```
1
2
Fizz
4
Buzz
```
